# Database
# ===========================
# Upper-bounded below 2.1: SQLAlchemy 2.1.0 (released 2026-09-24) changed
# the default "postgresql://" dialect's DBAPI resolution to require the
# psycopg (v3) package -- previously psycopg2-binary alone was sufficient.
# This broke every fresh CI install the same day with no code change on
# our side (ModuleNotFoundError: No module named 'psycopg', confirmed via
# a diagnostic CI run against the unmodified prior commit). Pinning below
# 2.1 restores the exact driver behavior already tested against this
# codebase; adopting 2.1 (and psycopg v3) should be a deliberate,
# separately-tested upgrade, not an accidental side effect of an
# unpinned floating dependency.
sqlalchemy>=2.0.0,<2.1.0
asyncpg>=0.31.0
psycopg2-binary>=2.9.12

# Auth & Security
# ===========================
# passlib[bcrypt] was evaluated and rejected: passlib 1.7.4 (unmaintained
# since 2020) hard-codes assumptions about bcrypt's internals that break
# under bcrypt>=4.1 (AttributeError reading `_bcrypt.__about__.__version__`,
# which bcrypt's own maintainers removed) -- reproduced directly against
# the version this repo installs. Using the actively-maintained `bcrypt`
# package directly (see src/auth/password_hashing.py) avoids that
# unmaintained shim entirely rather than pinning bcrypt to an old release
# forever.
